# AION 2 Party Assistant 0.1.23

## Русский

### Что нового

- **«Мой персонаж» больше не пишет «Kisk» вместо ошибки.** Если Kisk не успел
  ответить при запуске (например, ещё действует пауза между запросами к нему),
  карточка вашего персонажа показывала янтарную плашку «Kisk» и «Kisk не
  обновил страницу…» — хотя запроса к Kisk фактически не было. Теперь карточка
  говорит то же, что и остальные: красное «Ошибка» с настоящей причиной за
  кликом.
- Янтарная плашка «Kisk не обновил страницу…» осталась ровно для своего случая:
  Kisk **ответил** на обновление и вернул ту же дату обновления снаряжения, что
  уже была на карточке. Отказ по паузе, ошибка сети, лимит запросов и «нет
  профиля» — это не ответ, и плашка так больше не выглядит.
- Правило действует одинаково для вашего персонажа, участников группы,
  заявителей и персонажей рядом: все карточки читают один и тот же признак.
- Настройки, база, логи и остальное поведение программы не менялись.

### Требования

Без изменений: Windows 10 или 11, 64 бита; .NET устанавливать не нужно — среда
выполнения внутри папки программы. Для живого определения игры нужны Npcap с
поддержкой loopback и права администратора; ярлыки запускают программу с ними
сразу.

### Установка и обновление

- Запустите `Aion2PartyAssistant-0.1.23-setup.exe`. Поверх 0.1.22 установщик
  предложит «Обновить программу»; папка остаётся той, где программа уже стоит,
  данные в подпапке `data` сохраняются.
- Формат файла настроек и базы не менялся: 0.1.23 читает данные 0.1.22 без
  миграции. Новых переключателей нет.
- Программа запускается в конце установки сама, уже с правами администратора.

### Данные и удаление

- Настройки, кэш Kisk, база, сохранённый состав группы, история задержки и логи
  лежат в подпапке `data` рядом с программой — по умолчанию
  `D:\Aion2PartyAssistant\data`.
- «Удалить программу» удаляет саму программу, ярлыки и запись в списке
  установленных приложений; папка программы и подпапка `data` остаются.

### Известные ограничения

- Установщик не подписан: SmartScreen может предупредить, это ожидаемо.
- Npcap в установщик не входит (для его распространения нужна отдельная
  лицензия); установщик только проверяет наличие и показывает ссылку.
- Авто-принятия и авто-отклонения заявок нет: решение принимает игрок.
- Новая версия, не помеченная критической, никогда не устанавливается без
  нажатия «Скачать»; критическая — ставится при запуске и закрывает приложение.

## English

### What changed

- **«My character» no longer says «Kisk» where every other card says «Error».**
  When Kisk had not answered at launch — for instance because the per-character
  request pause was still running — the player's own card showed the amber
  «Kisk» chip and «Kisk has not refreshed the page yet», although no request had
  actually been made. The card now says what the others say: the red «Error»
  with the real cause behind the click.
- The amber «Kisk has not refreshed the page yet» notice now stands for exactly
  its own case: Kisk **answered** a refresh and returned the gear timestamp the
  card already held. A refusal by the pause, a network failure, a rate limit and
  «no profile» are not answers, and no longer look like one.
- The rule holds for the player's own character, party members, applicants and
  nearby characters alike: every card reads the same fact.
- Settings, the database, the logs and the rest of the program's behaviour are
  unchanged.

### Requirements

Unchanged: Windows 10 or 11, 64-bit; .NET does not have to be installed — the
runtime is inside the program folder. Live game detection needs Npcap with
loopback support and administrator rights, which the shortcuts request
themselves.

### Install and upgrade

- Run `Aion2PartyAssistant-0.1.23-setup.exe`. Over 0.1.22 it offers **Update the
  application**; the folder stays the one the program already uses and the data
  in the `data` subfolder is kept.
- The settings file and the database format are unchanged: 0.1.23 reads 0.1.22
  data without a migration. There are no new switches.
- The installer starts the program itself when it finishes, with administrator
  rights.

### Data and uninstall

- Settings, the Kisk cache, the database, the saved party roster, the latency
  history and the logs live in the `data` subfolder next to the program —
  `D:\Aion2PartyAssistant\data` by default.
- **Remove the application** removes the program, the shortcuts and the entry in
  Windows' installed-apps list; the program folder and its `data` subfolder stay.

### Known limitations

- The installer is not signed: SmartScreen may warn about it, which is expected.
- Npcap is not bundled with the installer (distributing it needs a separate
  licence); the installer only checks for it and shows a link.
- There is no auto-accept or auto-decline of applications: the player decides.
- A version not marked critical is never installed without pressing
  **Download**; a critical one is installed at launch and closes the app.
